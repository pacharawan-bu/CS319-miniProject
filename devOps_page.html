รายละเอียดงาน

CloudForge Labs กำลังมองหา DevOps Engineer ที่มีความเชี่ยวชาญด้านโครงสร้างพื้นฐานระบบ (CI/CD, Cloud, Infrastructure as Code) และกระตือรือร้นในการนำ AI Coding & Automation Tools (เช่น GitHub Copilot, Cursor, ChatGPT, Claude) มาช่วยเร่งความเร็ว เพิ่มความแม่นยำ และลดเวลาการบริหารจัดการระบบโครงสร้างพื้นฐาน

ความรับผิดชอบหลัก

  • ออกแบบ เขียน และดูแล Pipeline CI/CD, Script อัตโนมัติ (Bash, Python) และ Infrastructure as Code (Terraform, Ansible) ให้มีประสิทธิภาพสูง
  • ประยุกต์ใช้ AI ในการช่วยเขียน Script การ deployment, ตรวจหาข้อผิดพลาด (Debugging) ของ Pipeline และปรับปรุง Script ให้กระชับรวดเร็ว
  • ดูแลและบริหารจัดการ Cloud Infrastructure (AWS, Azure หรือ GCP), Containerization (Docker, Kubernetes) ให้รองรับการทำงานของระบบได้อย่างมั่นคง
  • ทำงานร่วมกับทีม Developer และ Tester เพื่อสร้างสภาพแวดล้อมการทำงาน (Environment) ที่เสถียร รองรับการทดสอบและการใช้งานจริงได้อย่างต่อเนื่อง
  • เฝ้าระวัง ติดตามประสิทธิภาพของระบบ (Monitoring & Logging) และนำ AI มาช่วยวิเคราะห์ Log เพื่อคาดการณ์ปัญหาก่อนเกิดขึ้นจริง
  • ดูแลด้าน Security & Compliance ในกระบวนการ DevOps (DevSecOps) เพื่อให้ระบบปลอดภัยและเป็นไปตามมาตรฐาน

คุณสมบัติ

  • ปริญญาตรี สาขาวิศวกรรมคอมพิวเตอร์, วิทยาการคอมพิวเตอร์, IT หรือสาขาที่เกี่ยวข้อง (หรือมีประสบการณ์ที่เทียบเท่าพร้อมผลงาน)
  • เชี่ยวชาญ CI/CD (GitHub Actions, GitLab CI, Jenkins) และ Containerization (Docker, Kubernetes)
  • มีความเข้าใจอย่างดีในเรื่อง Infrastructure as Code (Terraform) และระบบ Cloud
  • มีทักษะและความคุ้นเคยในการใช้ AI-Powered Tools ช่วยงาน Scripting และแก้ปัญหา Infrastructure
  • มีความรู้เรื่อง Git Version Control และกระบวนการทำงานแบบ Agile/DevOps
  • มีทักษะการแก้ปัญหาเฉพาะหน้า การคิดเชิงวิเคราะห์ และทำงานร่วมกับผู้อื่นได้ดี

สวัสดิการ

  • สิทธิ์ใช้งาน Pro License สำหรับ AI Tools ฟรี (GitHub Copilot, Cursor Pro, ChatGPT Plus ฯลฯ)
  • ประกันสุขภาพและประกันทันตกรรมระดับพรีเมียม
  • ค่าเรียนและงบสนับสนุนการฝึกอบรมพัฒนาทักษะทางเทคโนโลยี
  • กองทุนสำรองเลี้ยงชีพ (Provident Fund) พร้อมสมทบในอัตราพิเศษ
  • พื้นที่จัดกิจกรรม ฟิตเนส และสโมสรกีฬาของบริษัท
