AI-Assisted DBA & Data Analyst

สมัครงาน

  • เงินเดือน (บาท) : 40,000 - 70,000 บาท/เดือน (ขึ้นอยู่กับทักษะและประสบการณ์)
  • สาขาอาชีพหลัก : วิศวกรรมคอมพิวเตอร์/IT
  • สาขาอาชีพรอง : DBA / Data Analyst
  • รูปแบบงาน : งานประจำ

  • วันทำงาน : จันทร์-ศุกร์
  • วันหยุด : วันเสาร์, วันอาทิตย์
  • เวลาทำงาน : 09:00 - 18:00
  • ระดับตำแหน่งงาน : เจ้าหน้าที่ / ปฏิบัติการ

รายละเอียดงาน

CloudForge Labs กำลังเปิดรับสมัคร DBA & Data Analyst ที่มีความเชี่ยวชาญการบริหารจัดการฐานข้อมูลและการวิเคราะห์ข้อมูล พร้อมเปิดรับการใช้ AI Tools (เช่น ChatGPT, Claude, SQL AI Assistants) เข้ามาช่วยเร่งความเร็วในการเขียน Query, ปรับแต่ง Performance (Query Optimization) และสรุปผลข้อมูลเชิงลึก

ความรับผิดชอบหลัก

  • ออกแบบ บริหารจัดการ และดูแลความมั่นคงปลอดภัยของระบบฐานข้อมูล (Relational & NoSQL เช่น PostgreSQL, MySQL, MongoDB)
  • ประยุกต์ใช้ AI ในการช่วยวิเคราะห์ข้อมูล เขียน Complex SQL Query, Stored Procedures และทำการ Refactor คำสั่งให้ประมวลผลได้เร็วขึ้น
  • ติดตาม Performance Tuning, ทำ Indexing และแก้ไขปัญหา Bottleneck ของระบบฐานข้อมูล
  • จัดทำ Dashboard, Data Visualization และวิเคราะห์แนวโน้มข้อมูล (Data Insights) เพื่อสนับสนุนการตัดสินใจของทีมและผู้บริหาร
  • ทำงานร่วมกับทีม Backend และ Data Engineer ในการวางโครงสร้าง Data Architecture และ ETL Pipelines
  • วางแผนและดำเนินการสำรองข้อมูล (Backup), การกู้คืนข้อมูล (Disaster Recovery) และดูแลสิทธิ์การเข้าถึงข้อมูลตามมาตรฐานความปลอดภัย

คุณสมบัติ

  • ปริญญาตรี สาขาวิศวกรรมคอมพิวเตอร์, วิทยาการคอมพิวเตอร์, เทคโนโลยีสารสนเทศ, สถิติ หรือสาขาที่เกี่ยวข้อง
  • เชี่ยวชาญการใช้ภาษา SQL และการบริหารจัดการ RDBMS / NoSQL Database
  • มีทักษะการทำ Data Visualization (เช่น PowerBI, Tableau) หรือการใช้ Python/R ในการวิเคราะห์ข้อมูล
  • มีความเชี่ยวชาญหรือสนใจในการนำ AI Tools มาช่วยงาน Database Administration และการวิเคราะห์ Data
  • มีความเข้าใจเรื่อง Security, Data Governance และข้อกำหนดความปลอดภัยของข้อมูล
  • มีทักษะการสื่อสารดี สามารถถ่ายทอดข้อมูลทางเทคนิคให้เป็นเรื่องที่เข้าใจง่ายได้

สวัสดิการ

  • สิทธิ์ใช้งาน Pro License สำหรับ AI Tools ฟรี (GitHub Copilot, Cursor Pro, ChatGPT Plus ฯลฯ)
  • ประกันสุขภาพและประกันทันตกรรมระดับพรีเมียม
  • ค่าเรียนและงบสนับสนุนการฝึกอบรมพัฒนาทักษะทางเทคโนโลยี
  • กองทุนสำรองเลี้ยงชีพ (Provident Fund) พร้อมสมทบในอัตราพิเศษ
  • พื้นที่จัดกิจกรรม ฟิตเนส และสโมสรกีฬาของบริษัท
