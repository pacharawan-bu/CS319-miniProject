AI-Assisted Software Tester (QA Engineer)

สมัครงาน
  • สถานที่ : กรุงเทพมหานคร (ทุกเขต/อำเภอ)
  • เงินเดือน (บาท) : 40,000 - 70,000 บาท/เดือน (ขึ้นอยู่กับทักษะและประสบการณ์)
  • สาขาอาชีพหลัก : วิศวกรรมคอมพิวเตอร์/IT
  • สาขาอาชีพรอง : QA / Testing
  • รูปแบบงาน : งานประจำ
  • จำนวนที่รับ : 1 ตำแหน่ง
  • วันทำงาน : จันทร์-ศุกร์
  • วันหยุด : วันเสาร์, วันอาทิตย์
  • เวลาทำงาน : 09:00 - 18:00
  • ระดับตำแหน่งงาน : เจ้าหน้าที่ / ปฏิบัติการ

รายละเอียดงาน

CloudForge Labs กำลังมองหา QA / Tester ที่มีทักษะการทดสอบระบบทั้ง Manual และ Automation โดยมุ่งเน้นคนที่ชอบคิดค้นนำ AI Tools มาใช้ออกแบบ Test Scenario, สร้าง Test Cases อัตโนมัติ และเขียน Script การทดสอบ เพื่อให้การส่งมอบซอฟต์แวร์มีความรวดเร็วและปราศจากข้อผิดพลาด

ความรับผิดชอบหลัก

  • วางแผน ออกแบบ และดำเนินการทดสอบซอฟต์แวร์ (Functional, Regression, Integration, API และ Performance Testing)
  • ใช้ AI Coding & Prompts Assistants ในการช่วยสร้าง Test Cases, Edge Cases และเขียน Test Script (Cypress, Playwright, Selenium, Postman) ได้อย่างรวดเร็ว
  • ทำงานร่วมกับทีม Frontend, Backend และ PM เพื่อทำความเข้าใจ Requirement และชี้แจงปัญหา (Bugs) ได้อย่างชัดเจน
  • สร้างและดูแล Automation Test Suite ให้สามารถรันร่วมกับ CI/CD Pipeline ได้อย่างสมบูรณ์
  • บันทึก ติดตาม และสอบทานรายการ Bug ร่วมกับทีมพัฒนา เพื่อให้มั่นใจว่าได้รับการแก้ไขอย่างถูกต้องก่อน Release
  • ประเมินประสิทธิภาพระบบ (Load & Stress Testing) และตรวจสอบด้าน Accessibility / Cross-Browser ให้ได้มาตรฐาน

คุณสมบัติ

  • ปริญญาตรี สาขาวิศวกรรมคอมพิวเตอร์, วิทยาการคอมพิวเตอร์, IT หรือสาขาที่เกี่ยวข้อง (หรือมีประสบการณ์ตรงด้าน QA/Testing)
  • มีประสบการณ์การทำ Manual Testing และ Automation Testing (เช่น Cypress, Playwright, Robot Framework หรือ Selenium)
  • มีความเข้าใจการทดสอบ REST API (Postman, Bruno) และโครงสร้าง JSON
  • กระตือรือร้นในการนำ AI-Powered Development Tools เข้ามาช่วยสร้าง Test Case และเขียน Automation Script
  • มีทักษะการคิดวิเคราะห์อย่างเป็นระบบ ละเอียดรอบคอบ และช่างสังเกต
  • มีทักษะการสื่อสารและการทำงานเป็นทีมที่ดีเยี่ยม

สวัสดิการ

  • สิทธิ์ใช้งาน Pro License สำหรับ AI Tools ฟรี (GitHub Copilot, Cursor Pro, ChatGPT Plus ฯลฯ)
  • ประกันสุขภาพและประกันทันตกรรมระดับพรีเมียม
  • ค่าเรียนและงบสนับสนุนการฝึกอบรมพัฒนาทักษะทางเทคโนโลยี
  • กองทุนสำรองเลี้ยงชีพ (Provident Fund) พร้อมสมทบในอัตราพิเศษ
  • พื้นที่จัดกิจกรรม ฟิตเนส และสโมสรกีฬาของบริษัท
